# DDS Auth Core Backend

The central authentication, user identity, developer credentials, and verification server for the DDS ecosystem.

## Responsibilities
- User Registration & Session Token Management
- Developer Application Registration & Credential Hashes (Client ID / Client Secret)
- Allowed Origins Validation
- Verification Request Lifecycle & Socket.IO Real-time Events
- Verification Activity Logs
- Direct MongoDB Persistence

## Port
`http://localhost:5000`

## Run
```bash
npm run dev
```
