# DDS Developer Portal

The official administrative and developer portal for managing applications and credentials in DDS.

## Responsibilities
- Developer Application Lifecycle (Create, View, Status Toggle, Type-To-Confirm Delete)
- Client ID & Masked Client Secret Management
- Allowed Origins & Callback URLs Whitelisting
- Server-to-Server Connection Testing
- Developer Verification Audit Logs & Dashboard Analytics

## Port
`http://localhost:5174`

## Run
```bash
npm run dev
```
