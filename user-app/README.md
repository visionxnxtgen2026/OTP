# DDS User App

The official consumer identity & verification mobile web application for DDS.

## Responsibilities
- User Registration (Google Sign-In + Mobile Number + OTP)
- Session Gating & User Identity Token Storage
- Real-time Socket.IO Verification Requests
- Verification Challenge Modal (User manually enters 6-digit merchant code)
- User-scoped Activity Log & Connected Applications Management

## Port
`http://localhost:5173`

## Run
```bash
npm run dev
```
