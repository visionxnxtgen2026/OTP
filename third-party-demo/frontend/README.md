# DemoShop Frontend

The customer-facing merchant web application demonstrating DDS Auth checkout integration.

## Responsibilities
- Merchant Checkout & Verification UI
- Display 6-digit challenge code generated by DemoShop Backend
- Displays live DDS Auth Integration Health Badge
- Communicates **only** with DemoShop Backend (`http://localhost:5001`)

## Security Rules
- **NEVER** knows or stores the DDS Client Secret.
- **NEVER** communicates directly with DDS Auth Backend or MongoDB.

## Port
`http://localhost:5175`

## Run
```bash
npm run dev
```
